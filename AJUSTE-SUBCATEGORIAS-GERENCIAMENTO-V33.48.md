# V33.48 — Gerenciamento de subcategorias do Almoxarifado

- O botão `+` de Subcategoria agora abre um gerenciador no mesmo padrão visual e funcional de Categoria.
- É possível cadastrar novas subcategorias sem fechar o gerenciador.
- As subcategorias da categoria atual são listadas com quantidade de produtos vinculados.
- É possível remover subcategorias não utilizadas diretamente pelo ícone de lixeira.
- Se a subcategoria removida estiver selecionada no formulário, a seleção é limpa automaticamente.
- A regra do backend que impede excluir subcategorias em uso foi preservada.

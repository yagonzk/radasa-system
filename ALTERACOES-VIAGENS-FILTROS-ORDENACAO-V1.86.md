# Radasa System v1.86 — Filtros da aba Viagens + ordenação por data

## Filtros
A aba **Viagens** agora utiliza o mesmo padrão de filtros da aba **Romaneios**:
- campo de pesquisa geral;
- filtros diretamente nos cabeçalhos das colunas;
- indicador visual no cabeçalho quando o filtro está ativo;
- pesquisa dentro das opções de cada filtro;
- botão Limpar em cada filtro;
- botão geral Limpar filtros.

Foram adicionados filtros para:
- Data do manifesto, com período De/Até;
- Placa;
- Motorista;
- Destino;
- KM;
- Frete;
- Custos;
- Custo/KM;
- Lucro Bruto.

## Ordenação
As viagens são sempre ordenadas da **data mais recente para a mais antiga**.
Quando duas viagens possuem a mesma data de manifesto, a criada mais recentemente aparece primeiro.

Exemplo: uma viagem de 21/08/2026 aparece antes de uma viagem de 20/08/2026.

Sem migration nova.

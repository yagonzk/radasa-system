# Radasa System v1.56 — Dashboard de Romaneios

- Dashboard de Romaneios alinhado visualmente ao dashboard de Abastecimentos.
- Cards com a mesma altura mínima e comportamento responsivo.
- Botão de ocultar/mostrar valor fixado no canto superior direito do card, separado do valor.
- Valores não são mais deslocados pelo ícone do olho.
- Cabeçalho da página usa o mesmo comportamento responsivo de Abastecimentos.
- Conteúdo de Romaneios passa a utilizar toda a largura disponível, como Abastecimentos.
- Sem alteração de banco de dados e sem migration nova.

# Radasa System v1.94 — Filtros pesquisáveis no padrão Romaneios

Na aba Fiscal > Análise Romaneios:

## Cliente
Ao clicar em **Cliente**, agora o pop-up:
- mostra **Todos os clientes** como primeira opção;
- mostra diretamente a lista completa de clientes;
- possui a mini barra **Pesquisar cliente...**;
- possui rolagem para listas grandes;
- mostra um check no cliente selecionado;
- possui Limpar e OK no rodapé.

Não existe mais um segundo dropdown dentro do filtro.

## Produto
O filtro **Produto** recebeu exatamente o mesmo padrão:
- Todos os produtos;
- lista completa;
- mini pesquisa;
- rolagem;
- check do selecionado;
- Limpar e OK.

O comportamento segue o mesmo modelo já utilizado na aba Romaneios.

Sem migration nova.

# Radasa System v1.71 — Lista de estoque e ordenação por número de fogo

## Aba Cadastro
- A lista passa a ser ordenada pelo **Número de fogo do maior para o menor**.
- O pneu com maior número de fogo fica sempre no primeiro registro da tabela.
- A ordenação natural também funciona para números com prefixos/textos.

## Aba Estoque
- Adicionada uma lista completa mostrando somente pneus cujo status é **ESTOQUE**.
- A lista exibe: Nº de fogo, Marca/Modelo, Medida, ARO, Condição, Tipo, Sulco atual, Compra e Ações.
- Os cards de Novo, Usado, Recapado e Aguardando recapagem agora contam somente pneus realmente em estoque.
- A lista de estoque também é ordenada pelo maior Número de fogo primeiro.

Sem migration nova.
